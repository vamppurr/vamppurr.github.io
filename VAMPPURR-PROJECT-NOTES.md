# VampPurr — шрифты и резервная копия решений

Основной шрифт: Handjet Variable. Шрифт для логотипа и части заголовков: CHAVAK (авторская модификация). Дополнительные пиксельные элементы: High Pixel-7. Резерв: Iosevka Charon Mono Regular.

Все 4 гарнитуры уже встроены прямо в index.html в виде data URL. Для работы сайта отдельные файлы не нужны. Это сделано специально для простой загрузки с телефона.

## Как активировать Iosevka в будущем

В CSS внутри index.html найти правило `body{font-family:"HandjetVP"` и заменить в нём `"HandjetVP"` на `"IosevkaReserve"`. Если нужно заменить Handjet вообще везде, заменить `"HandjetVP"` на `"IosevkaReserve"` во всех CSS-правилах ПОСЛЕ секции с @font-face. Само встроенное содержимое шрифта при этом не менять.

## Наиболее важные решения по дизайну

Почти полностью чёрно-бело-серый интерфейс, без скруглений. Индустриальные рамки и небольшие терминальные метки. Цвет в основном в авторских пиксельных иллюстрациях. На главной минимум картинок, одна главная композиция. Сменные сезонные арты. Музыка — компактный блок Coming Soon на главной, без отдельной страницы. В планах: расписание, игры + скриншоты, кино, стримы, клипы, прохождения Boosty / YouTube, сетап, pixel art. Хостинг — GitHub Pages, репозиторий vamppurr/vamppurr.github.io.
